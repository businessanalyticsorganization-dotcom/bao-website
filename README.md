# BAO website

This is a lightweight, mobile-first website for the Business Analytics Organization.

## Publish with GitHub Pages

1. Create a new GitHub repository named `bao-website`.
2. Upload these files and the BAO logo image.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, select `/ (root)`, then save.
5. GitHub will show the public web address after it finishes publishing.

Before publishing, replace the placeholder contact link in `index.html` with BAO's official Instagram, Linktree, email, or campus-engagement page.
